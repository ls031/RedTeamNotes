
## john-the-ripper

如果不清楚破解的format 有哪几种格式。使用以下命令
```
sudo john --list=formats
```


破解 MD5
纯MD5
```
# 字典爆破（必须显式指定 raw-md5 格式）
john --format=raw-md5 --wordlist=/usr/share/wordlists/rockyou.txt md5.txt

# 看结果
john --show md5.txt
```

Unix MD5
```
# 合并 passwd 和 shadow 
unshadow passwd shadow > hashes 
john --format=md5crypt hashes --wordlist=/usr/share/wordlists/rockyou.txt
```


破解 id_rsa 的 passphrase

```
ssh2john my_ssh_key > ssh_hash.txt
john --wordlist=wordlist.txt ssh_hash.txt
```

## fuff fuzz 测试网站接口参数

根据 workinginprogress.php 界面的提示，当前界面可能存在一个可以命令执行的入口点。

![p6](../vulnhubScreenShot/Vulnhub%20bossplayersCTF%20靶机渗透总结/IMG-20261030145340765.png)

我们猜测，这个注入参数肯定是以 GET 或者 POST 方式进行传参的。我们使用 Fuff 工具来猜测这个可能的借口参数。 Fuff 工具会通过指定的字段，在请求访问过程中的指定位置上填写参数名，向服务器发包，如果服务器返回与其他请求不同的结果说明，这个请求的参数名很可能是开发者遗漏的参数。

这是错误的写法，FUZZ 就是我们指定要猜解的参数名。注意等号后面我们不能填写 1 ，最好填写一条可以执行的命令，这样当命令执行成功和执行失败返回的响应包的数据大小是不一样的。
